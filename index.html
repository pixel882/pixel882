Część pierwsza: iteracja po tabliach (v-for)

Pętla po prostych tablicach:

  • {{ item }}

Tablica z indeksem (item, i):

  • {{ i }}: {{ item }}

Pętla po tablicy obiektów:

  • {{ i }}{{ item.subject }}

Uwaga: dodaj element do tablicy z poziomu konsoli js:

app.array.push('React')

Część druga: iteracja po obiektach (v-for)

ul 1 - value key obiektu

  • {{ key }}: {{ val }}

ul 2 - key value index obiektu

  • {{ index }} - {{ key }}: {{ val }}
